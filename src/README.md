# Портфолио

Главная (`/`): кто я и какую роль ищу, главные технологии, контакты → карточки проектов
(что это, задача, моя роль, стек, инженерные детали, демо, код) → профиль → технологии.
Дальше три страницы-проекта: StarWise → ChinaShipments → POME.
У каждого проекта: описание, архитектура (цепочка слоёв), сторона клиента (этапы, фронт и бэк),
сторона владельца (админ-панель с метками; у POME — блок «Как считается»),
инженерные решения, стек, контакты.
Языки: RU / EN. Цвет акцента у каждой страницы — под цвет проекта.

## Что нужно заполнить

Всё в одном файле — `src/site.config.js`:

| Что | Где |
|---|---|
| Название в шапке и во вкладке браузера | `brand` |
| Имя на главной | `person` |
| Telegram, почта, GitHub, LinkedIn | `contacts` |
| Ссылки проектов: демо, демо-админка, бот, TikTok, документация API | `links` |
| Ссылка на код проекта (только публичный репозиторий) | `links.<проект>.repo` |
| Роль и срок по каждому проекту | `meta` |

Пустое значение — кнопка или строка на сайте не показывается, сломанных ссылок не будет.

## Запуск

```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/
```

## Деплой на Vercel

1. Залить папку в новый репозиторий GitHub.
2. Vercel → Add New → Project → выбрать репозиторий. Framework: Vite (определяется сам).
3. `vercel.json` уже настроен: адреса `/starwise`, `/chinashipments` и `/pome` открываются
   напрямую и переживают обновление страницы (F5).

## Адреса страниц

| Адрес | Что открывается |
|---|---|
| `/` | главная |
| `/starwise`, `/chinashipments`, `/pome` | страницы проектов |
| `/StarWise/`, `/index.html` и т. п. | та же страница, адрес приводится к обычному виду |
| любой другой | страница 404 (с `noindex`) |

Новый проект = файл в `src/content/` с полем `path` + строка в `src/content/index.js`:
вкладка в шапке, карточка на главной и маршрут появятся сами.

На другом хостинге нужна такая же настройка, как в `vercel.json`: все адреса отдают
`index.html` (на Netlify — файл `public/_redirects` со строкой `/* /index.html 200`).

## Где что лежит

```
src/
  site.config.js        имя, контакты, ссылки, роль и срок
  content/
    about.js            главная: позиционирование («начинающий разработчик»), описание,
                        профиль, список технологий
    starwise.js         тексты и цвета проекта (RU + EN): card — карточка на главной,
                        arch — архитектура, decisions — инженерные решения
    chinashipments.js
    pome.js             в т.ч. числа блока «Как считается»
    ui.js               общие подписи (кнопки, заголовки)
    index.js            порядок проектов
  components/           шапка, страница проекта, страница 404, блоки
  router.jsx            маршруты: адрес в строке браузера → страница
  styles.css            оформление
public/img/             скриншоты проектов
```

- Пометить проект как незавершённый — блок `status` в его файле (см. `starwise.js`):
  метка на карточке и в шапке страницы, строка «Статус», пояснение под описанием.
  Убрать блок — метка исчезнет.
- Логотип-волна — компонент `Wave` в `src/components/Header.jsx`, иконка вкладки —
  `public/favicon.svg`.
- Поменять порядок проектов — переставить их в `src/content/index.js`
  (номера 01 / 02 / 03 проставятся сами).
- Поменять цвет проекта — `colors` в его файле (`fill` — кнопки, `text` — акцент на светлом,
  `onDark` — акцент на тёмном).
- Заменить скриншот — положить файл с тем же именем в `public/img/`. Если меняется скриншот
  админки, поправить `markers` (положение меток в процентах от ширины и высоты картинки).

## Демо-админка StarWise

Файл `admin-demo.html` кладётся в проект демо StarWise: `starwise-demo/public/admin-demo.html`.
После деплоя он открывается по адресу `<сайт демо>/admin-demo.html` — эту ссылку вписать
в `links.starwise.admin`.
